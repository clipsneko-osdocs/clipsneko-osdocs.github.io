# 啟動安裝程式
進入 Hyprland 桌面後，使用我們的快捷鍵 **SUPER + T** 以啟動我們的終端 kitty
::: tip 提示
您可以將 SUPER 鍵視為 PC 鍵盤上的 Windows 鍵或 Mac 鍵盤上的 Command 鍵。我們的觸發方式要求您先按住 SUPER 鍵，再按住其他鍵。
:::
在 kitty 成功啟動後，輸入 ->
```bash
clipsneko-installer
```

安裝程式通常以 Live 環境中的普通使用者 installer 執行，並且，一些小巧思使得安裝程式不需要密碼。並且，installer 使用者和 root 也都是無密碼的。

因此，如果您是經驗豐富的使用者，也可以在另一臺機器上 ssh 到目標機器進行安裝，這也是我們採用 TUI 的原因。不過，在這裡您就需要給連線的目標使用者設定密碼了（當然，不會影響到安裝程式的提權）。

快捷鍵說明在安裝程式的底邊，每一步也許不同。您可以使用 `Tab` 在內容區域和底部按鈕之間切換焦點，使用方向鍵選擇專案，使用 `Enter` 確認。
