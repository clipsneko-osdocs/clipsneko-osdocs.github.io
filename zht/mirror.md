# 映象選擇
::: tip 提示
絕大部分 GNU/Linux 發行版都有線上軟體源，您可以通過使用包管理器，簡單的安裝軟體、配置，而無需從原始碼編譯或是手動下載構建產物。
:::
我們提供了映象源組的選擇和自定義映象源 ->
![](../img/mirror.webp)

您需要根據您的地區選擇一個較近的映象源組，如您是澳大利亞的使用者，可以選擇 Australia.

::: tip 提示
映象源組均包含幾個映象，這些映象伺服器都在選定的地區。在對應的地區訪問會享受到低延遲與可能的高頻寬。
:::

## 手動設定映象源（高階）
您可在最下方手動輸入映象源的連結。映象源的連結必須為完整的連結（有源資料庫檔案的那一層級）。對於您手動設定的源，安裝程式會進行驗證，此時可能會有一段時間的操作凍結。
