# 語言與本地化設定
在安裝程式啟動後，您可以看到 ->
![](../img/language.webp)

左側為安裝程式的語言選擇選單，為單選；右側為 locale 選擇選單，為多選。

使用 **Tab** 鍵以在不同表格、按鈕中切換，使用 **方向鍵** 切換選項，使用 **Space** 鍵以選定選項。

在左側選擇的語言在右邊會（可取消勾選）。在設定完成後，使用 **Tab** 鍵移動游標至下一步，或直接按下 **Enter** 鍵，都會進入到下一步。

## 選擇啟用的 locale
在任意 GNU/Linux 發行版中，如果要顯示一種語言，就必須生成對應語言的語言環境。非常幸運的是，ClipsNeko Linux 會將此過程自動化。您需要選擇想啟用的語言，安裝程式會自動處理該過程。

通常，您只需要切換安裝程式的語言到您準備在最終系統中使用的語言，對應的 locale 會自動啟用。同時，若您在給其他語言的使用者安裝 ClipsNeko Linux, 也可取消勾選您的 locale, 並選擇目標使用者的語言，同時只在安裝程式中使用您的語言。

您可以上下瀏覽，並使用 **Space** 鍵來啟用 locale.

::: warning 注意
必須選定至少一個 locale。
:::

## 定義 LANG 變數
LANG 變數決定了您在終端預設使用的語言，擁有本地化能力的程式絕大多數均遵守該變數。

在 ClipsNeko Linux 中，我們選擇定義 `/etc/locale.conf` 來設定全域性 LANG 變數。幸運的是，這個過程也是安裝程式代勞的。

您可以使用 **L** 鍵來選擇一個 locale 作為 LANG 變數。同時，若按下鍵 **L** 時選擇的 locale 沒有被選定啟用，該 locale 就會自動被選定啟用。

您會注意到，右側 locale 選擇選單中有一個選項的標記為 `*` ，而其他選項為 `x` 。我們把將作為 **LANG 變數**的 locale 標記為 `*` ，而**啟用的其他** locale 標記為 `x`。
::: warning 注意
同時只能存在一個被設定為 LANG 變數的 locale，並且 LANG 變數必須是被選定啟用的 locale 之一。
:::

## 選擇鍵盤
您或許知道世界上有很多種類不同的鍵盤，相同的訊號輸入可能代表完全不同的按鍵。於是，我們也同時提供了鍵盤型別的選擇 ->
![](../img/keyboard.webp)

如果您在使用非 en 的鍵盤，您一定知道這是什麼，並且知道自己使用的是什麼鍵盤。在列表中選擇即可。

如果您不知道這是什麼，那麼恭喜您，眼前的鍵盤是 en 鍵盤，可以直接按 **Enter** 跳過這一步。
