# 磁碟分割槽
您需要一個或多個**空閒的分割槽**來安裝作業系統。ClipsNeko Linux 支援基於 Btrfs 裝置池的軟 RAID0 以及 RAID1。
::: tip 提示
為保證體驗，您需要至少 **20 GiB 的空閒空間**來安裝 ClipsNeko Linux.
:::
::: danger 警告
使用 `cfdisk` 會修改分割槽表。請提前檢查是否有重要資料，並仔細核對選擇的裝置與進行的操作。由此造成的分割槽資料丟失，ReSpring ClipsNeko Co., Ltd. 無法對此負責。
:::
選擇磁碟以使用 `cfdisk` 進行分割槽 ->
![](../img/diskpart.webp)
您可以看到最左側顯示的裝置路徑。通常，如果您使用 SATA 硬碟，那麼硬碟的裝置路徑會顯示為形如 **sda** 或 **sdb** 以及 **sdc** 等等類似 **sd?** 的形式, 而 USB 驅動器也會顯示為此型別。在此情況下，您需要核對後面的型號和容量。

如果您使用的是 NVME 硬碟，這種情況下裝置路徑會顯示為 **nvme0n1** 等形式，這時它們是您的機器內建硬碟，可以選擇它們並按 **Enter** 以使用 `cfdisk`.

對選擇的裝置按 **Enter** 即可開啟 `cfdisk`.

如果您的磁碟沒有分割槽表（新磁碟）->
![](../img/cfdisk0.webp)
您會看到裝置需要新建一個分割槽表。這時，選擇 **gpt**.
::: tip 提示
因為 ClipsNeko Linux 使用 UEFI, 需要使用 GPT 分割槽表。
:::

在成功建立分割槽表之後，您可以看到 ->
![](../img/cfdisk1.webp)
按下左右方向鍵，可以在選項之間移動。按下上下方向鍵，可以在分割槽之間移動（這時，我們還沒有分割槽）。

選擇 **New** 以建立一個新的分割槽 ->
![](../img/cfdisk2.webp)
您可以填寫分割槽大小。這包括單位，**M** 表示 **MiB**，而 **G** 表示 **GiB**.

對於 ClipsNeko Linux, 我們需要 ->
- **ESP (EFI system partition)**，至少需要 **64 MiB** 的空間。
- **用於安裝作業系統的空間（由一個或多個分割槽組成）**，至少需要共 **20 GiB** 的可用空間（大於 20 GiB）。

剛才建立了 ESP 分割槽，再建立一個用於安裝作業系統分割槽 ->
![](../img/cfdisk3.webp)
然後調整 ESP 分割槽的型別 ->
![](../img/cfdisk4.webp)
![](../img/cfdisk5.webp)
在這裡，選擇 **EFI System** 以將 ESP 分割槽設定成正確的型別。

回到主介面後，選擇 **Write** 以將改動寫入硬碟 ->
::: danger 警告
這一步將會修改分割槽表。請提前檢查好修改是否符合預期。
:::
您需要輸入 **yes** 以確認分割槽表的修改。
![](../img/cfdisk6.webp)

最後，選擇 **Quit** 以退出 `cfdisk`.

## 跨多分割槽安裝
您需要確保最終選擇的分割槽，經過您選擇的 RAID 選項計算之後，可用空間大於 20 GiB（不包括 20 GiB）。

### Btrfs RAID 可用空間計算方式
Btrfs 支援兩種 RAID 型別：
- RAID 0: 僅作分割槽融合，容量為分割槽容量之和（因後設資料為 RAID 1, ClipsNeko Linux 計算可用容量的方式僅為最小的分割槽容量的兩倍）
- RAID 1: 映象兩個磁碟，總容量為最小分割槽的容量。

因此 ->
| 示例        |   型別  |  大小  | 可安裝 |
| :---------: | :----: | :----: | :---: |
| 10 + 10 GiB | RAID 0 | 20 GiB | 否    |
| 10 + 12 GiB | RAID 0 | 20 GiB | 否    |
| 11 + 12 GiB | RAID 0 | 22 GiB | 是    |
| 10 + 10 GiB | RAID 1 | 10 GiB | 否    |
| 10 + 12 GiB | RAID 1 | 10 GiB | 否    |
| 20 + 20 GiB | RAID 1 | 20 GiB | 是    |
相信通過這個表格您可以瞭解 ClipsNeko Linux 的可用空間計算。

選擇下一步，以進入到分割槽角色分配 ->
![](../img/diskinst.webp)
在這裡，您可以看到存在的可用分割槽。

從左到右，分別是：

**裝置路徑** **分割槽大小** **分割槽型別** **角色** **檔案系統**

您在這一步需要設定的是**分割槽的角色**。

在我們的安裝程式中，有以下角色：
- **ESP**：EFI 系統分割槽，有且只有一個，具有 GPT EFI 系統分割槽型別，使用 vfat 檔案系統。
- **安裝目標**：系統將格式化為 Btrfs，並將在其中自動建立 `@` 和 `@home` 子卷。可以選擇一個或多個。
- **未分配**：該分割槽不會被安裝程式使用。

您需要做的，就是將前文中建立的幾個分割槽分配好它們的角色。

按 **Enter** 彈出角色選擇選單，並選擇角色以分配。

::: warning 提示
只能存在**一個 ESP 分割槽**，可以選擇**多個安裝目標分割槽**。
:::

如果您正確的分配了分割槽角色，就可以進入到下一步了。
