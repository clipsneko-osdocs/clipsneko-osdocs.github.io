# 選擇核心
為了不同的用途，ClipsNeko Linux 提供了多種 Linux 核心選擇 ->
![](../img/kernel.webp)

這些核心的功能與效能各不相同，您可以選擇最適合自己的那個：
- **linux**：通用核心。上游 Arch Linux 的預設核心。
- **linux-lts**：長期支援核心。通常版本較舊，穩定性和相容性最好，不過不適合新硬體。
- **linux-zen**：針對桌面互動最佳化的核心，ClipsNeko Linux 預設選項。
- **linux-hardened**：強化安全配置的核心，可能與一些程式不適配。
