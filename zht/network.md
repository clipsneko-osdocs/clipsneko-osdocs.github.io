# 網路設定
我們是滾動發行版，採用網路安裝，這樣可以使您直接獲取到最新的軟體包與安全更新。

因此，安裝過程需要網路連線。

如果您的電腦這時候插著網線，那麼您可能看到類似如下的頁面 ->
![](../img/network.webp)

這表示您已經連線到網路，可以直接進行下一步了。

如果顯示 **Disconnected**, 這說明您需要進行網路配置。因為有線網路一般暢通，本篇只專注於無線網路的描述。如有疑難雜症，請聯絡網路業務提供商獲取幫助。

## 使用 Network Manager TUI
在顯示 **Disconnected** 的頁面，按下 **Enter** 鍵，會自動開啟 Network Manager TUI, 也就是運行了命令 `nmtui`.
![](../img/nmtui.webp)
選擇 **Activate a connection**, 之後在 **Wi-Fi** 一欄，就可以看到環境中存在的無線網路的 SSID 了。選擇您的網路，然後按 **Enter**，再輸入密碼……大功告成。

按 **Tab** 切換游標至 **Back**, 然後 **Quit** 以退出 `nmtui`, 之後網路狀態會自動重新整理。一旦您成功連線網路，就可以進行下一步了。

如果您沒有看到任何 SSID, 而您確認附近存在無線網路，這可能是RFKill子系統在軟體層面停用了無線網絡卡。此時您可以嘗試使用 **SUPER + 2** 切換至工作區 2，按 **SUPER + T** 再開啟一個 kitty, 使用命令 ->
```zsh
sudo rfkill unblock all
```
以解除對無線網絡卡的限制。

按 **SUPER + 1** 切換回工作區 1，退出 `nmtui`, 再重試一次，如果依然不行，很大機率上是您的硬體過新，而 Linux 核心主線驅動樹還未支援。這時，您可以尋找社群驅動，或者更換無線網絡卡。不過，這些都是有一定技術需求的操作。而本文受限於篇幅與硬體的多變性，無法詳細講解。
