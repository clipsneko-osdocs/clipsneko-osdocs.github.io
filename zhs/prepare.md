# 安装 ClipsNeko Linux

本文介绍如何使用 ClipsNeko Linux Live CD 和 TUI 安装程序完成 ClipsNeko Linux 的安装。

::: danger 警告

安装过程中选中的目标分区会被格式化，造成已有数据丢失。请提前检查是否有重要数据，并在最终确认页面逐项核对磁盘、ESP 分区和安装目标。由此造成的数据丢失，ReSpring ClipsNeko Co., Ltd. 无法对此负责。

:::

## 安装前准备

### 确认硬件条件

- **一台 x86_64 架构（建议为2008年以后的CPU）、支持 UEFI 启动的 PC。**
- **至少 2GiB 的内存**（Live CD 上的 Hyprland 需要 2GiB 的内存）。
- 一个拥有**大于 20 GiB 可用空间（不包括 20 GiB）的安装目标分区**（或使用 Btrfs RAID0，可用空间计算如下述）。
- **一个可用的网络连接。**
- 一个用于制作启动盘的 U 盘（可用空间需大于 2GiB）。

安装程序只支持 UEFI + GPT，不支持传统 BIOS + MBR 安装方式。
您可以关闭会阻止启动第三方系统的安全启动，或者为 Live 镜像配置相应的签名信任。

#### Btrfs RAID 可用空间计算方式
RAID 0 : 选定的最小分区大小 * 2

RAID 1 : 选定的最小分区大小
| 示例       |   类型  |  大小  |
| :--------: | :----: | :----: |
| 8 + 10 GiB | RAID 0 | 16 GiB |
| 8 + 10 GiB | RAID 1 | 8 GiB  |
| 8 + 12 GiB | RAID 1 | 8 GiB  |

### 制作安装介质并启动 Live CD

1. 下载 ClipsNeko Linux Live CD iso ->
https://repo.clipsneko.cc/iso/latest/clipsneko-x86_64.iso
2. 使用工具将其写入到USB驱动器或者刻录光盘（不建议）

    推荐使用写入工具 [balenaEtcher](https://mirrors.bfsu.edu.cn/github-release/balena-io/etcher/LatestRelease/)
    或 [Ventoy](https://www.ventoy.net/en/download.html)
3. 重启后按主板厂商的指引设置USB启动或选择USB启动（若失败请先[关闭安全启动](https://www.google.com/search?q=how+to+disable+secure+boot)）
4. 等待进入 tty 环境之后，会自动登录 installer 用户，稍作片刻等待，就会启动 uwsm ->
![alt text](../img/image.webp)
5. 按 Enter 进入 Hyprland 桌面。

::: tip 提示
如果在引导时循环重启，并且Systemd log输出往往是到和网络相关的部分卡住

关机，然后拔掉电源线，等待十秒以上再插电开机
:::


## 安装步骤

### 1. 语言和区域设置

首先选择安装程序界面语言，然后选择目标系统要启用的 UTF-8 区域设置。

- 安装程序语言只影响当前安装界面。
- 默认区域设置会写入目标系统的 `/etc/locale.conf`，作为 `LANG`。
- 其他勾选的区域设置会写入 `/etc/locale.gen` 并由 `locale-gen` 生成。
- 至少保留一个区域设置，不能删除最后一个已选项。

中文用户通常可以选择 `zh_CN.UTF-8` 作为默认区域设置，并按需要同时启用 `en_US.UTF-8`。

### 2. 键盘布局

从列表中选择键盘布局。安装程序会立即在 Live 环境中加载布局，并将选择写入目标系统的 `/etc/vconsole.conf`。

如果无法确认布局，请先使用 Live 环境测试数字、字母和常用符号，避免安装后无法正常输入密码。

### 3. 网络

安装程序会打开网络配置界面。连接无线网络时选择对应的网络并输入密码；使用有线网络时通常可以直接使用自动配置。

返回安装程序后，它会检查是否能够访问网络。网络检查未通过时不能进入下一步，请先确认网卡已启用、时间基本正确，并重新配置网络。

### 4. 软件仓库镜像

从列表中选择距离较近的仓库区域。所选区域的服务器会被移动到仓库列表前面，并通过包管理器验证。

如果需要使用特定镜像，可以切换到手动输入，填写完整的 `Server =` 地址。手动输入会作为唯一启用的服务器，避免验证时回退到其他镜像。验证失败时请检查地址、网络连接和系统时间。

### 5. 磁盘和分区

这是最需要谨慎的步骤。安装程序分为磁盘选择和分区角色分配两个页面。

#### 编辑分区表

在磁盘选择页面选中要安装系统的物理磁盘，按 `Enter` 打开 `cfdisk`。你可以在离开页面前编辑多块磁盘的分区表。

请在 `cfdisk` 中确保磁盘使用 GPT 分区表，并准备至少两个分区：

- 一个 EFI 系统分区（ESP），通常为 512 MiB 到 1 GiB，类型必须是 `EFI System`。
- 一个或多个用于安装系统的分区，容量必须大于 20 GiB。

安装程序会保护承载 Live 环境的启动盘和只读磁盘，但它们可能仍显示在列表中。不要仅凭磁盘大小或型号判断设备，务必同时核对设备路径、型号和容量。

完成分区后退出 `cfdisk`，安装程序会重新读取分区表。若刷新失败，请重新打开 `cfdisk` 检查分区表后再试。

#### 分配分区角色

在分区角色页面，为分区分配以下角色：

- `ESP`：EFI 系统分区，只能选择一个，并且必须具有 GPT EFI 系统分区类型。
- `安装目标`：系统将格式化为 Btrfs，并创建 `@` 和 `@home` 子卷。可以选择一个或多个。
- `未分配`：该分区不会被安装程序使用。

选择多个安装目标时需要选择 Btrfs 数据配置：

- `RAID0`：容量优先，数据分布在多个分区上；任一分区损坏都可能导致数据丢失。
- `RAID1`：冗余优先，数据保留副本，可用容量会受到镜像开销影响。

无论选择哪种数据配置，元数据都使用 `RAID1`。所有安装目标都会被格式化；已有文件系统和数据不会保留。ESP 如果不是 FAT32，也会在安装时格式化为 FAT32；已经是 FAT32 的 ESP 会直接复用。

### 6. 内核

选择目标系统的内核：

- `linux`：通用内核。
- `linux-lts`：长期支持内核。
- `linux-zen`：针对桌面交互优化的内核，默认选择。
- `linux-hardened`：强化安全配置的内核。

安装程序会自动安装所选内核对应的头文件包和 `linux-firmware`。

### 7. NVIDIA 驱动

没有 NVIDIA 显卡时选择不安装驱动。有 NVIDIA 显卡时，根据所选内核选择兼容的驱动：

| 内核 | 可选驱动 |
| --- | --- |
| `linux` | `nvidia-open`、`nvidia-open-dkms` |
| `linux-lts` | `nvidia-open-lts`、`nvidia-open-dkms` |
| `linux-zen` | `nvidia-open-dkms` |
| `linux-hardened` | `nvidia-open-dkms` |

不兼容的选项会在界面中标记并跳过。默认选项为 `nvidia-open-dkms`。安装 NVIDIA 驱动时，安装程序会在生成 initramfs 前移除 `kms` 钩子。

### 8. 时区

安装程序会尝试根据网络信息预选时区；检测失败或无法识别时使用 `UTC`。你也可以按地区和具体时区手动选择，例如 `Asia/Shanghai`。

选择完成后，目标系统会建立 `/etc/localtime` 链接，并运行 `hwclock --systohc` 同步硬件时钟。

### 9. 用户账户

填写用户名、密码和确认密码。用户名必须由小写字母、数字、下划线或连字符组成，并以小写字母或下划线开头。

安装程序会创建一个加入 `wheel` 组、默认 shell 为 `/bin/zsh` 的用户，并启用 wheel 组的 `sudo` 权限。密码强度条仅用于提示；非空且两次输入一致的密码即可继续。

### 10. 主机名

填写单个主机名。主机名只能包含 ASCII 字母、数字和连字符，长度为 1 到 63 个字符，不能以连字符开头或结尾，也不能填写完整域名。

主机名会写入 `/etc/hostname`，并添加到目标系统的 `/etc/hosts`。

### 11. 确认安装

安装程序会显示安装摘要，包括区域设置、键盘布局、内核、NVIDIA 驱动、时区、用户名、主机名、受影响的磁盘、ESP、所有安装目标以及 RAID 配置。

密码不会显示在摘要中。选择安装前请重点确认：

1. 受影响的物理磁盘是否正确。
2. ESP 是否位于预期磁盘上。
3. 每一个安装目标是否都可以被格式化。
4. 多分区 Btrfs 是否选择了正确的数据配置。

确认对话框默认选中取消，需要手动选择安装后才会进入实际安装阶段。

### 12. 安装和重启

安装程序会依次执行以下操作：

1. 格式化安装目标，创建 Btrfs 的 `@` 和 `@home` 子卷并挂载。
2. 挂载或格式化 ESP。
3. 使用 Live 环境的仓库配置安装基础软件包、所选内核、固件和 NVIDIA 驱动。
4. 生成并校验 `/etc/fstab`，为根目录和家目录保留 Btrfs 压缩挂载选项。
5. 配置时区、区域设置、键盘、主机名、用户账户和 sudo 权限。
6. 生成 initramfs，安装并配置 GRUB UEFI 引导程序。
7. 启用 NetworkManager，并为新用户安装 ClipsNeko 默认配置。

安装期间不要关闭终端、退出安装程序或重启计算机。安装失败时不会自动回滚，当前挂载会保持不变；可以查看安装日志，或返回启动安装程序的 shell 进行检查。

安装成功后，选择立即重启。重启前请拔出 Live U 盘，或在固件启动菜单中选择已安装系统的 UEFI 启动项。如果选择暂不重启，安装程序会退出，但会保留 `/mnt` 挂载以便检查。

## 常见问题

### 网络检查失败

先返回网络配置界面重新连接。确认可以访问 Arch Linux 软件仓库，并检查系统时间；错误的系统时间可能导致 HTTPS 连接或仓库签名验证失败。

### 找不到安装目标分区

返回磁盘页面，使用 `cfdisk` 创建分区后退出，让安装程序重新读取分区表。不要手动依赖分区设备名称推测关系，以安装程序最新显示的磁盘和分区列表为准。

### ESP 分区无法选择

该分区可能不是 GPT EFI 系统分区。使用 `cfdisk` 将分区类型设置为 `EFI System`，然后重新进入分区角色页面。

### 安装后无法启动

确认计算机以 UEFI 模式启动，并在固件启动项中选择 `clipsneko`。如果仍无法启动，请使用 Live U 盘检查 ESP 是否挂载到 `/boot/efi`，以及目标磁盘是否被固件识别。

### 安装失败后如何处理

不要直接重复执行可能已经完成的破坏性操作。先在失败对话框中查看日志，记录失败命令和错误信息；确认目标分区、网络和仓库配置无误后，再从 Live 环境重新开始安装。
