# 镜像选择
::: tip 提示
绝大部分 GNU/Linux 发行版都有在线软件源，您可以通过使用包管理器，简单的安装软件、配置，而无需从源码编译或是手动下载构建产物。
:::
我们提供了镜像源组的选择和自定义镜像源 ->
![](../img/mirror.webp)

您需要根据您的地区选择一个较近的镜像源组，如您是澳大利亚的用户，可以选择 Australia.

::: tip 提示
镜像源组均包含几个镜像，这些镜像服务器都在选定的地区。在对应的地区访问会享受到低延迟与可能的高带宽。
:::

## 手动设置镜像源（高级）
您可在最下方手动输入镜像源的链接。镜像源的链接必须为完整的链接（有源数据库文件的那一层级）。对于您手动设置的源，安装程序会进行验证，此时可能会有一段时间的操作冻结。
