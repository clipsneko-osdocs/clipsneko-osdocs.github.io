# 选择内核
为了不同的用途，ClipsNeko Linux 提供了多种 Linux 内核选择 ->
![](../img/kernel.webp)

这些内核的功能与性能各不相同，您可以选择最适合自己的那个：
- **linux**：通用内核。上游 Arch Linux 的默认内核。
- **linux-lts**：长期支持内核。通常版本较旧，稳定性和兼容性最好，不过不适合新硬件。
- **linux-zen**：针对桌面交互优化的内核，ClipsNeko Linux 默认选项。
- **linux-hardened**：强化安全配置的内核，可能与一些程序不适配。
