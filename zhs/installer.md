# 启动安装程序
进入 Hyprland 桌面后，使用我们的快捷键 **SUPER + T** 以启动我们的终端 kitty
::: tip 提示
您可以将 SUPER 键视为 PC 键盘上的 Windows 键或 Mac 键盘上的 Command 键。我们的触发方式要求您先按住 SUPER 键，再按住其他键。
:::
在 kitty 成功启动后，输入 ->
```bash
clipsneko-installer
```

安装程序通常以 Live 环境中的普通用户 installer 运行，并且，一些小巧思使得安装程序不需要密码。并且，installer 用户和 root 也都是无密码的。

因此，如果您是经验丰富的用户，也可以在另一台机器上 ssh 到目标机器进行安装，这也是我们采用 TUI 的原因。不过，在这里您就需要给连接的目标用户设置密码了（当然，不会影响到安装程序的提权）。

快捷键说明在安装程序的底边，每一步也许不同。您可以使用 `Tab` 在内容区域和底部按钮之间切换焦点，使用方向键选择项目，使用 `Enter` 确认。
