# User settings
For security reasons, you cannot log in directly as root (unless you are experienced enough to already know how to configure it). Instead, create a regular user and use that user to escalate privileges to root.

You can set a username and password ->
![](../img/account.webp)
The username cannot contain spaces.

The ClipsNeko Linux installer has a password-strength indicator. It is only an indicator; although simple passwords are not recommended, you can still create an account with one.
